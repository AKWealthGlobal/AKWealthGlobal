# 考卷 A → B 卷

## 流程

1. **讀取 A 卷**
   - PDF：先抽文字；抽不到（掃描檔）就把頁面轉成圖片再讀。
   - Word（.docx）：讀出段落、表格與方程式。
   - 圖片：直接看圖辨識，包含手寫的題號、表格、幾何圖形。
   - 把結構列成清單：標頭（學校、班級、姓名、考試名稱）、大題、題號、配分、題型、圖表。

2. **逐題設計 B 題**。每一題都要：
   - **題型與考點相同**：例如一元一次方程式 `2x + 3 = 7`，換成 `3x − 5 = 10`。
   - **難度相同**：計算步驟數、是否有負數、分數或括號，都要和原題一致。
   - **答案乾淨**：原題答案是整數，B 題答案也要是整數，除非原題本來就是分數或小數。
   - **圖形題**：保留圖的構造，只換標示的數值；換完要確認幾何上仍然成立，例如三角形兩邊之和大於第三邊。
   - **表格題**：保留欄位與自變數，換函數式，例如 `y = 2x + 1` 換成 `y = −x + 3`。
   - **選擇題**：換題幹數值，並重新設計誘答選項，正確答案的位置也要打散。

3. **驗算**：每一題 B 題都要用 Python（sympy 或手算程式）實際算出答案，確認有解、答案唯一，而且和解答一致。驗算失敗就重新出題，不要交出沒驗算過的題目。

4. **輸出**
   - 格式與 A 卷相同：A 卷是 Word 就輸出 Word；是 PDF 或圖片就輸出 Word 加 PDF。
   - 標頭照抄，標題中的「A 卷」改成「B 卷」，其他標頭欄位不變。
   - 題號、配分、版面順序、空白作答區都和 A 卷一致。
   - 另外輸出一份**解答卷**：每題寫答案與簡要計算過程。

5. **回報**：用表格列出每題 A 和 B 的對照，以及驗算結果。

## 規則

- 不改題目數量、配分與作答區大小。
- 有看不清楚的字或圖，先標出來請使用者確認，不要猜。
- 數學式在 Word 裡用方程式物件或清楚的上下標，不要用「x^2」這種純文字寫法。
