# 市場簡報 / 投資分析

## 流程

1. **確認範圍**：標的（代號）、時間區間（今日 / 本週 / 本月）、輸出語言（預設繁體中文）。使用者沒講就用預設：本週、繁中。
2. **取得資料**（依優先順序）：
   - 加密貨幣：若有 Gemini MCP 工具（`mcp__Gemini__gemini_get_ticker`、`gemini_list_candles`），優先使用。
   - 股票 / ETF / 總經：用 WebSearch / WebFetch 或 Firecrawl 抓公開來源（交易所、央行、主要財經媒體）。
   - 每個數字都要記下**來源與時間點**。拿不到的數據寫「未取得」，絕不臆測或編造。
3. **撰寫報告**，使用下方範本。
4. 若使用者提供持倉（標的、數量、成本），計算市值、未實現損益、權重，並標出單一標的權重 > 25% 的集中風險。

## 報告範本

```markdown
# 市場簡報｜{日期區間}

## 重點摘要
- 3–5 條，每條一句話，先講結論

## 行情一覽
| 標的 | 收盤 | 區間漲跌 | 備註 |
|------|------|----------|------|

## 驅動因素
- 總經 / 政策 / 財報 / 資金流，各附來源

## 風險與觀察清單
- 下週值得注意的事件（數據公布、財報日、會議）

## 資料來源
- [來源名稱](URL) — 取得時間

> 免責聲明：本內容僅供資訊參考，不構成任何投資建議。投資有風險，請自行判斷。
```

## 規則

- 不做「買進 / 賣出」的個人化建議；可以列出多空觀點與各自理由。
- 百分比保留兩位小數，金額標明幣別。
- 一律附上免責聲明。
