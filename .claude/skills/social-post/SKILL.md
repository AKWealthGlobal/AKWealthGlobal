# 社群內容 / 行銷文案

## 品牌設定（請依實際情況修改）

- 品牌：AK Wealth Global
- 語氣：專業、可信、清楚；不浮誇、不保證報酬
- 受眾：關注財富管理與全球投資的個人與企業
- 預設語言：繁體中文 + 英文對照

## 流程

1. 確認：平台、主題 / 素材、目標（曝光 / 互動 / 導流）、是否需要英文版。未說明時預設 LinkedIn + 繁中英雙語。
2. 依平台規格撰寫（見下表），每次提供 **2 個版本** 供挑選。
3. 附上建議 hashtag（3–5 個）與 CTA。

| 平台 | 長度 | 重點 |
|------|------|------|
| LinkedIn | 150–300 字 | 首行抓注意力，段落短，專業觀點 |
| Facebook | 80–200 字 | 口語、易分享 |
| Instagram | 50–150 字 | 首句即重點，配圖建議 |
| X / Threads | ≤ 280 字元 | 一個觀點，一個 CTA |
| 電子報 | 400–800 字 | 標題 + 摘要 + 3 個段落 + CTA |

## 輸出格式

```
【版本 A】
（繁中）
（English）
Hashtags: #...
CTA: ...
配圖建議: ...

【版本 B】
...
```

## 合規規則

- 不得承諾或暗示保證獲利、「穩賺」「零風險」等用語。
- 引用數據須附來源。
- 涉及投資內容時，結尾加一行：「投資有風險，內容僅供參考。」/ "For informational purposes only. Not investment advice."
