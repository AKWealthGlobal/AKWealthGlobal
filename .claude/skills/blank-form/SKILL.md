# 已填表格 → 空白表格

## 流程

1. **辨識結構**
   - 標題、副標題、表頭說明文字，例如日期欄、活動名稱。
   - 表格的欄位名稱、欄數、列數、欄寬比例、合併儲存格。
   - 分清楚哪些是**固定內容**，哪些是**填寫內容**：
     - 固定：標題、欄位名稱、預先印好的編號（1、2、3…）、說明文字、勾選框的選項文字。
     - 填寫：姓名、單位、簽名、手寫日期、勾選記號、印章。
   - 分不清時，例如某欄看起來像預印也像手寫，先問使用者。

2. **重建空白表**
   - 保留所有固定內容，清空所有填寫內容。
   - 列數與原表相同；使用者要求的話可以加列，例如「做 30 列」。
   - 編號欄：原表有預印編號就保留，並延續到所有列。
   - 簽名欄留足夠高度，列高不小於原表。

3. **輸出格式**
   - 原檔是 Excel → 輸出 Excel，並保留欄寬與框線。
   - 原檔是 Word → 輸出 Word。
   - 原檔是圖片或 PDF → 預設輸出 Word（方便再編輯）加 PDF（方便列印）；使用者指定格式時以指定的為準。
   - 檔名：`<原檔名>-空白.<副檔名>`。

4. **回報**：列出保留的欄位、清空的欄位與列數，請使用者確認。

## 規則

- 原表中的個人資料（姓名、簽名、電話等）只用來判斷欄位，不寫進輸出檔，也不在回覆中重複列出。
- 不自行新增或刪除欄位，除非使用者要求。
- 標題中的年份或日期如果像是填寫內容（手寫或另外打字），就清空並保留底線或空格。
