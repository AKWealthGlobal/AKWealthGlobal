# Ken 親子財商教室｜進階財商主題企劃

主題範圍：風險管理、區塊鏈、比特幣、加密貨幣、K 線、美股、外匯、PESTLE、資產配置。
這份是主題企劃，只列主題、故事方向和注意事項，還沒寫六格腳本。

- **讀者**：台灣讀者。金額用新台幣，K 線用台灣的紅漲綠跌，法規以台灣主管機關（金管會、財政部等）為準。
- **角色**：以 **Ken IP 的 Q 版形象**製作。外型、髮型、服裝、配色一律以使用者提供的 Ken 原作素材為準，不自行改造，也不用其他角色冒充 Ken。兒童篇可以在「萬獸城」的動物城市裡發生，和網站上的親子遊戲串連。
- **畫面規範**：比照 Alice 系列的 Q 版六格規範：直式 2×3 共六格、2～2.5 頭身、繁體中文對白、逐字核對。螢幕和圖表用簡化圖示，不畫真實券商、交易所、App 的商標和介面，也不畫真實鈔票圖案。K 線圖一律用紅色代表漲、綠色代表跌。
- **編號**：KA（5–8 歲）、KB（9–12 歲）、KC（成年人與親子共讀），不和 Alice 系列的 K1–K8 撞號。

## 一、原始企劃分析

原始企劃的故事點子很有畫面感，但有幾個**事實錯誤**和**不適合兒童的方向**，要先修正：

### 1. 事實錯誤

| 原文 | 問題 | 修正 |
|---|---|---|
| K 線「綠色代表買方強、紅色代表撤退」 | 這是美國的配色。**台灣是紅漲綠跌**，台灣讀者會被教錯 | 一律改成紅漲綠跌；講美股時再補充「美國剛好相反」 |
| 兔子村「大豐收」，所以小熊幣換到的糖變少 | 邏輯相反：糖大豐收，糖應該變便宜。而且這講的是物價，不是匯率 | 改成「兔子村辦慶典，大家都想換兔子幣」，所以兔子幣變貴（需求影響匯率） |
| 「連壞狐狸也無法偷改紀錄」 | 區塊鏈的紀錄很難竄改，但**錢包密碼被偷、交易所倒閉、詐騙**才是常見的損失，原文會讓人以為加密貨幣很安全 | 加上「帳本改不了，但鑰匙掉了、被騙了，錢一樣拿不回來」 |
| 美股下跌時，黃金和「某些加密貨幣」可以對沖 | 加密貨幣和股市常常一起漲跌，不是可靠的避險工具 | 刪掉加密貨幣對沖的說法；強調「沒有永遠有效的避險」 |
| 「比特幣總共 2100 萬顆」 | 這個說法正確 | 保留，但補充「限量不代表一定有價值，要有人想要才有價值」 |

### 2. 不適合兒童的方向

依網站規範，**兒童區不做金融商品導流**。原始企劃有三個地方要改：

| 原文 | 問題 | 修正 |
|---|---|---|
| 9–12 歲學看 K 線「掌握進出場時機」 | 等於教小孩短線交易 | 改成「K 線是價格的日記」，教看懂過去，不教預測未來 |
| 9–12 歲用「美股 vs 加密貨幣」學資產配置 | 直接把孩子帶向特定商品 | 改用烏龜、兔子、火箭比喻穩健、成長、高風險，不放真實商品 |
| 成年人「外匯交易員秒殺 K 線、生死博弈」 | 美化當沖和高槓桿交易 | 改成一般人的視角：升息怎麼影響房貸、出國和存款 |

### 3. 觀點要平衡的地方

- **「反抗軍用比特幣對抗銀行巨頭」**：立場太單邊。改成「信任銀行、政府，還是程式碼？」，各自說出優點和風險，讓讀者自己判斷。
- **「全天候防禦陣讓主角優雅生還」**：容易讓人以為有完美的配置。改成「黑天鵝來時，有預備金和分散的人比較睡得著」，不保證不賠。

### 4. 和現有 Ken 漫畫的關係

現有的 10 篇 Ken 六格漫畫（鴻源、FTX、LUNA、im.B、JPEX、1929、1989 日本泡沫、1997 亞洲金融風暴、2000 網路泡沫、2008 金融海嘯）都是「歷史案例」。這份企劃改走「**觀念和工具**」路線，可以互相引用：

- 加密貨幣風險篇 → 延伸閱讀 FTX、LUNA、JPEX
- 黑天鵝、資產配置篇 → 延伸閱讀 1929、2008
- Alice 的通膨三部曲（M1–M3）→ 可以當作 KB 系列的前導

## 二、分析框架

### 1. Maslow：把理財放回人生需求

| 層次 | 理財對應 | 本企劃主題 |
|---|---|---|
| 生理 | 生活費夠用 | KC04 預備金 |
| 安全 | 預備金、保險、防詐、分散風險 | KA01、KA02、KB07、KB09、KC03、KC04、KC06、KC10 |
| 愛與歸屬 | 全家一起談錢、不因錢吵架 | KC09 |
| 尊重 | 看懂新聞與工具，不被話術牽著走 | KB01、KB02、KB03、KC02、KC07 |
| 自我實現 | 為夢想做長期規劃 | KB06、KC08 |
| 自我超越 | 理解科技與制度對社會的影響 | KC01、KB08 |

**結論**：財商教育要先顧好「安全」層（預備金、保險、防詐），再談「成長」（投資、配置）。所以本企劃的每個年齡層，都從風險管理開始。

## 四、建議製作順序

1. **先做三個年齡的風險管理**：KA01 → KB09 → KC04。先建立「安全第一」的觀念，再談投資工具。
2. **再做最容易被騙的主題**：KB07 → KC03 → KC10。和現有的 FTX、JPEX 漫畫，以及 165 防詐串連。
3. **最後做工具和觀念**：KB01 → KB02（K 線一定要兩篇一起做）→ KB03 → KB05 → KB06。

確定主題後，可以展開成六格腳本。腳本格式比照 Ken 現有的六格漫畫，Ken 的形象使用原作素材。
