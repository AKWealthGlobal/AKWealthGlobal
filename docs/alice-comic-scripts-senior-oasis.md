# Alice AI 學院｜中老年人心靈小站（樂齡學堂追加篇）

這份是「樂齡學堂」的追加腳本，主題是「**時光不老，科技有溫度**」。角色沿用林阿姨、王伯伯、孫子小寶，另外新增陳奶奶（秋月）。畫面規範和 Codex 指令範本沿用主檔 `alice-comic-scripts.md`；樂齡篇的大字、高對比規則照舊。

編號用 **O01–O12**（Oasis，心靈綠洲），不和其他系列撞號。

### 2. 參考資料需要調整的地方

| 原文 | 問題 | 改法 |
|---|---|---|
| 「換臉」做圓夢照 | 臉部資料外流的風險；換成別人的臉也有肖像權問題 | 只用長輩本人的照片，本人同意；選擇不保存照片的工具，或用完就刪 |
| 「我想聽鄧麗君，AI 立刻播放」 | 播放要透過有授權的音樂平台，可能需要訂閱或有廣告 | 漫畫畫成通用的音樂 App；家長說明寫「可能需要訂閱」 |
| AI 作曲 | 不能請 AI 模仿真實歌手的聲音 | 只用心情關鍵字作曲，例如「思鄉、午後、鄉間小路」 |
| 「24 小時不嫌煩的聊天夥伴」 | 可能取代真人陪伴，加深孤立 | 已有 N05 處理；這系列每篇都把長輩帶回人群 |
| 「同理心健康小幫手」 | AI 的健康建議可能不適合每個人 | 示範「問 AI → 帶去問營養師或醫師」 |
| 拍藥罐讓 AI 唸出來 | 讀錯會有用藥風險 | 已有 D2 處理：用藥以藥師、醫師為準 |

### 3. 用 Maslow 和 PESTLE 補缺口

**Maslow**：現有的樂齡和長照篇集中在「生理」和「安全」（看病、吃藥、防詐）。心靈小站把重心往上移：

| 層次 | 本系列主題 |
|---|---|
| 生理 | O06 低鹽版的拿手菜、O08 每天一題腦力遊戲 |
| 安全 | O10 想清楚，家人才不用猜（預立醫療決定）、O11 網路上的溫柔醫生（交友詐騙） |
| 愛與歸屬 | O01 金婚婚紗照、O03 老歌房、O05 寫信給老伴 |
| 尊重 | O02 當年沒走的那條路、O07 編織老師、O09 一次只學一步 |
| 自我實現 | O04 我的專屬旋律 |
| 自我超越（傳承） | O12 阿公的人生錦囊 |

**PESTLE**：

| 面向 | 本系列主題 |

| S 社會（孤獨、喪偶、數位落差、世代互動） | O03、O05、O09、O12 |

| P 政治 | 同上 |

### 4. 查證過的資料（O10）

- 台灣的《病人自主權利法》讓有完全行為能力的人，先到提供服務的醫院做「預立醫療照護諮商」（ACP），再簽署「預立醫療決定」，由醫院上傳並註記在健保卡上。
- 諮商是自費項目，中低收入戶有減免；可以和家人一起參加，也可以指定醫療委任代理人。
- 收費和辦理方式可能調整，漫畫裡不寫金額，只寫「先問醫院或衛生局」。
- 來源：[衛生福利部](https://mohw.gov.tw/cp-4343-45985-1.html)、[公視新聞網](https://news.pts.org.tw/article/426377)

### 5. 製作補充規範（心靈小站專用）

參考資料的操作清單很實用，轉成漫畫的畫面規則：

- **語音優先**：長輩操作 AI 的畫面，優先畫「用說的」，少畫打字。
- **一格一步**：示範操作的格子，每格只做一個步驟。
- **孫子式教學**：教長輩的人說話溫柔、用鼓勵的口氣，不畫不耐煩的表情（O09 是例外，這篇刻意演出不耐煩，再示範怎麼改）。
- **回到人群**：每篇最後一格，長輩都和家人、朋友或社區在一起，不是一個人對著手機。

## 三、腳本

### O01　五十年前沒拍的婚紗照
**slug：** `oasis-golden-wedding-photo`

1. 【畫面】林阿姨和王伯伯翻相簿，結婚那頁只有一張黑白的合照，兩人穿著普通的衣服。
   林阿姨：「那時候窮，連婚紗照都沒拍。」
2. 【畫面】小寶聽到，眼睛一亮，拉著 Alice 過來。
   小寶：「下個月是金婚紀念日，我們來補拍！」
3. 【畫面】Alice 先問兩位長輩。
   Alice：「用你們現在的照片做婚紗照，好嗎？」
   王伯伯：「好啊，讓我再當一次新郎！」
4. 【畫面】AI 生成的照片：兩位長輩穿著白紗和西裝，站在開滿花的教堂前，臉還是現在的樣子。
   小光：「保留你們現在的臉，只換衣服和背景。」
5. 【畫面】Alice 指著手機設定。
   Alice：「臉部照片很重要，做完記得刪掉上傳的原檔。」
6. 【畫面】金婚宴上，放大印出來的婚紗照擺在中間，全家圍著兩人鼓掌。
   林阿姨：「五十年了，終於等到這一張。」
   照著說：「請保留這兩個人的臉和年紀，讓他們穿上白紗和西裝，背景是開滿花的花園，溫暖自然的光線。」

   陳奶奶：「我想當歌星呢！」

   Alice：「我們讓 AI 幫大家拍一張『夢想照』！」

### O03　點點老歌房
**slug：** `oasis-oldies-room`

   陳奶奶：「好久沒聽以前的歌了……」

   Alice：「想聽什麼，直接跟手機說。」
3. 【畫面】陳奶奶對著手機說話，有點不確定。
   陳奶奶：「我想聽……七〇年代的老歌。」
4. 【畫面】音符從手機飄出來，陳奶奶跟著哼，眼睛閉起來。
   小光：「為您播放 1970 年代的懷念老歌。」
5. 【畫面】陳奶奶打電話給以前的老同事。
   陳奶奶：「阿玉，我們以前常唱的那首歌，妳還記得嗎？」
6. 【畫面】社區活動中心，陳奶奶和老朋友們圍著手機一起唱歌，有人打拍子。
   陳奶奶：「一首歌，把大家都找回來了！」
   照著說：「播放 1970 年代的【語言】老歌」「播放【歌手名字】的歌」「這首歌叫什麼名字？」
   > 家長說明：播放音樂要透過有授權的音樂平台，可能需要訂閱，或會有廣告。

### O04　我的專屬旋律
**slug：** `oasis-my-melody`

1. 【畫面】王伯伯坐在田埂邊的老家門口（回憶畫面），旁邊是夕陽和稻田。
   王伯伯：「好想念老家的那條小路。」
2. 【畫面】回到現在，小寶拿著平板。
   小寶：「阿公，我們用 AI 把這種感覺做成音樂！」
3. 【畫面】Alice 在白板寫下三個框框：心情、地方、樂器。
   Alice：「說出三個詞就好。」
   王伯伯：「思鄉、稻田、口琴。」
4. 【畫面】平板播出一段溫柔的口琴旋律，王伯伯閉上眼睛。
   小光：「這是專屬於王伯伯的〈稻田小路〉。」
5. 【畫面】王伯伯聽完，搖搖頭，請小寶再調整。
   王伯伯：「再慢一點，像傍晚走回家那樣。」
   Alice：「不滿意就再說一次，這首歌是你的。」
6. 【畫面】家族聚會，大家聽著〈稻田小路〉，王伯伯驕傲地說這是他「作」的曲。
   王伯伯：「我七十歲，第一次當作曲家！」
   照著說：「做一段【心情】的純音樂，讓人想到【地方】，主要樂器是【樂器】，速度慢一點，大約一分鐘。」

### O05　寫一封信給老伴
**slug：** `oasis-letter-to-late-spouse`

> 這篇處理喪偶的悲傷，畫面以安靜、溫暖的色調為主，不畫哭得很誇張的表情。

1. 【畫面】陳奶奶坐在老伴的照片前，桌上兩杯茶，一杯沒人喝。
   陳奶奶：「老伴走了一年，還有好多話沒說。」
2. 【畫面】女兒在網路上看到「AI 讓逝去的親人復活說話」的廣告，猶豫地拿給 Alice 看。
   女兒：「要不要讓爸爸的照片動起來，跟媽媽說話？」
3. 【畫面】Alice 溫柔地搖頭。
   Alice：「AI 說的話不是他說的，可能讓人更難放下。」
4. 【畫面】Alice 建議換一種方式：請 AI 陪陳奶奶把想說的話整理成一封信。陳奶奶對著手機慢慢說。
   陳奶奶：「謝謝你，陪我走了五十年……」
5. 【畫面】小光把她說的話整理成一封信，一字一句都是陳奶奶自己的話。
   小光：「我只整理順序，沒有改您的意思。」
6. 【畫面】清明節，陳奶奶和女兒在老伴墓前唸信，女兒握著她的手。
   陳奶奶：「說出來，心裡就輕一點了。」
   照著說：「我想寫一封信給【對象】，我會說出想說的話，請幫我整理成一封信，只用我說的內容，不要加入我沒說過的話。」
   安心專線框：心裡很難過、走不出來時，可以打衛福部安心專線 1925（24 小時）。

### O06　低鹽版的拿手菜
**slug：** `oasis-low-salt-recipe`

5. 【畫面】Alice 提醒，林阿姨拿著清單去社區營養諮詢站。

   王伯伯：「味道還是老婆的味道！」
   照著說：「我有【健康狀況】，請把【菜名】改成比較健康的做法，列出食材怎麼換、調味怎麼減，步驟寫簡單一點。」

### O08　每天一題腦力遊戲
**slug：** `oasis-brain-games`

1. 【畫面】早上，王伯伯在公園做完早操，坐下來休息。

   王伯伯：「是『告』字！」
   小光：「答對了！」
5. 【畫面】隔天，王伯伯把題目帶到公園考老朋友，大家搶著猜。
   老朋友：「再出一題、再出一題！」
6. 【畫面】一群長輩在公園玩成語接龍，笑聲不斷。
   Alice：「動動腦，也動動嘴，和朋友一起玩最開心。」
   照著說：「出 3 題【猜燈謎／成語接龍／腦筋急轉彎】給我，等我回答了再告訴我答案。」

### O09　一次只學一步
**slug：** `oasis-one-step-at-a-time`

1. 【畫面】小寶教阿嬤用手機傳照片，手指飛快地點來點去。
   小寶：「就這樣、這樣、再這樣，很簡單啊！」
2. 【畫面】林阿姨一臉茫然，小寶不耐煩地嘆氣。
   林阿姨：「你點太快了……我是不是太老了，學不會？」
3. 【畫面】Alice 把小寶拉到一旁，溫柔地說。
   Alice：「你剛學騎腳踏車時，阿嬤也是慢慢扶著你。」
4. 【畫面】小寶把步驟寫成三張大字小卡：①打開相簿 ②點照片 ③按「分享」。
   小寶：「阿嬤，我們一次只學一步。」
5. 【畫面】林阿姨自己點，成功把照片傳到家族群組，小寶拍手。
   小寶：「阿嬤好厲害！」
6. 【畫面】林阿姨把小卡收進皮包，下次又學會了新的一步；小寶在旁邊耐心等。
   林阿姨：「慢慢學，我也學得會！」
   照著說：「請教我【想學的事】，分成 3 個步驟，每個步驟一句話，用最簡單的說法。」

### O10　想清楚，家人才不用猜
**slug：** `oasis-advance-directive`

> 這篇主題比較嚴肅，畫面維持溫暖明亮，重點是「全家一起好好談」。

1. 【畫面】王伯伯去醫院探望老朋友，老朋友插著管子，家人在病房外為了要不要急救而爭吵。
   家屬：「爸爸到底想不想要？我們都不知道……」
2. 【畫面】回家路上，王伯伯若有所思。
   王伯伯：「我不想讓孩子這樣為難。」
3. 【畫面】晚上，王伯伯請 AI 用白話解釋「預立醫療決定」。
   小光：「就是先想清楚，在某些重病情況下，您想不想接受某些醫療。」
4. 【畫面】Alice 補充說明，背景是三個簡單的步驟圖示：問醫院→全家一起諮商→簽署、註記在健保卡。
   Alice：「要先到醫院做諮商，細節和費用要問醫院或衛生局。」
5. 【畫面】週末，全家圍坐在餐桌前，王伯伯說出自己的想法，孩子們認真聽。
   王伯伯：「我想先跟你們說清楚我的想法。」
6. 【畫面】一家人和醫院的諮商團隊坐在一起，氣氛溫和。
   女兒：「謝謝爸爸，我們以後就不用猜了。」
   照著說：「請用簡單的話解釋『預立醫療決定』是什麼，並列出我可以問醫院的 5 個問題。」

### O11　網路上的溫柔醫生
**slug：** `oasis-romance-scam`

1. 【畫面】陳奶奶收到一則交友訊息，大頭貼是一位穿白袍、笑容溫和的外國醫生。
   假醫生：「您好，我在國外當醫生，看到您的照片覺得很親切。」
2. 【畫面】接下來幾週，兩人每天聊天，對方噓寒問暖，陳奶奶的笑容變多了。
   陳奶奶：「好久沒人這樣關心我了。」
3. 【畫面】有一天，對方說要寄禮物來，但要先付「關稅」。
   假醫生：「禮物卡在海關，請先匯 5 萬元。」
4. 【畫面】女兒發現了，請 Alice 一起看。Alice 指著大頭貼：皮膚太光滑、背景模糊、耳環一邊有一邊沒有。
   Alice：「這很可能是 AI 做出來的假照片。」
5. 【畫面】陳奶奶有點難過，女兒抱著她，一起撥打 165。
   女兒：「媽，不是妳的錯，是騙子太會騙了。」
6. 【畫面】陳奶奶參加社區的舞蹈班，和真實的朋友們一起跳舞。
   Alice：「沒見過面就要你匯錢的，一定先停下來問家人。」
   照著說：「有一位網友【對方說的話】，請幫我列出可能是詐騙的地方。」
   提醒框：網路上認識、沒見過面，卻要你匯款、買點數或付關稅的，先打 165 反詐騙專線。

### O12　阿公的人生錦囊
**slug：** `oasis-life-advice-capsule`

1. 【畫面】王伯伯參加孫女的國小畢業典禮，感慨地看著她。
   王伯伯：「等她結婚的時候，我不知道還在不在……」
2. 【畫面】Alice 拿出一個發光的「錦囊」。
   Alice：「把想對她說的話先錄下來，留到那一天。」
3. 【畫面】王伯伯對著手機錄音，旁邊有三個信封：「考上大學那天」「第一次工作那天」「結婚那天」。
   王伯伯：「找工作不要只看薪水，要找一個讓你每天想早起的地方。」
4. 【畫面】小光把錄音轉成文字，整理成三封信，每封都保留阿公原本的口吻。
   小光：「阿公說的台語俗語，我也保留下來了。」
5. 【畫面】王伯伯把信和錄音檔交給女兒保管，叮嚀她時間到了再打開。
   王伯伯：「時間到了，再給她看喔。」
6. 【畫面】多年後（未來畫面），長大的孫女穿著婚紗，聽著阿公的錄音，笑著擦眼淚；王伯伯坐在第一排，頭髮更白了，正在鼓掌。
   孫女：「阿公，你的錦囊我收到了。」
   照著說：「我會說一段想對【對象】說的話，請幫我整理成一封信，保留我說話的口吻和俗語，不要加入我沒說過的內容。」

## 四、搭配實體活動的建議

如果要在社區關懷據點或長青學苑辦活動，可以搭配：

| 漫畫 | 活動 |
|---|---|
| O01、O02 | 圓夢照相館：現場生成、印出照片，帶回家留念 |
| O03、O04 | 點點老歌房：一起點歌、一起做專屬旋律 |

| O12 | 人生錦囊錄音日：志工協助長輩錄音、整理成信 |

活動時照主檔的樂齡規範：大字、語音優先、一次一步、多鼓勵。
