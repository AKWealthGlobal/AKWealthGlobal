# 追加漫畫發布前校稿紀錄

目前狀態：校稿預覽，尚未核准正式發布。

## 已核對項目

- 11 篇漫畫、66 格分鏡，逐格標題、場景文字和對白取自三份追加漫畫校稿 Markdown；原有角色名稱、繁體中文用字和標點保留。
- 原始插畫依每張圖實際分隔線重新裁格，避免把相鄰格帶入畫面。可以辨識留白氣泡的格子已排入該格第一句主要對白；完整角色台詞仍以逐格文字稿呈現。
- 每格圖片有場景替代文字；手機 390px 和 320px 預覽均未出現水平溢位，逐格文字為 17px。
- O01 平板和手機畫面已標明為插畫示意，不代表任何特定工具已驗證隱私功能、保存或刪除承諾。
- O05 的 1925 與 O11 的 165 資訊連至衛福部和警政署官方頁面。
- Ken 角色肖像使用 Ken 參考素材生成；仍待 Ken 確認肖像風格及品牌使用。

## 尚待人工處理

- O11 第 1、4、5、6 格及 O02 第 4 格沒有足以排入對白的留白氣泡。請決定補繪氣泡，或核准這些格改以圖下對白呈現；目前全文保留在可讀的逐格文字稿中。
- 對白自動排版目前每格只放入一個主要句子。含兩位以上角色的格子，其餘台詞保留在逐格文字稿；請在正式發布前逐格確認氣泡尾端指向與說話角色一致。
- Ken 肖像確認完成前，不應將相關漫畫提升為正式品牌內容。

## 技術驗證

- `npm run typecheck`：通過。
- `npm run build`：通過；漫畫目錄和 11 篇詳情頁皆成功靜態輸出。
- 手機版檢查：390px、320px 均未發現水平溢位；此為本機瀏覽器檢查，並非實體手機測試。
