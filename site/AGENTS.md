# AK Wealth Global 協作規則

- 所有對外文字使用繁體中文；品牌、產品名稱及網址保留原文。
- Next.js App Router、TypeScript。預設伺服器元件，互動狀態才使用用戶端元件。
- 首頁維持海軍藍、青色與暖金；內容頁使用高對比淺色閱讀區。
- 手機優先檢查 390×844、320px 寬及桌面。主要操作至少 48px，字級避免低於 16px 的主要內容。
- Ken IP 使用使用者提供的原作素材，不用故事裡的其他角色冒充 Ken。
- 漫畫提供逐格與原圖閱讀；不得擅改原作文字。
- 兒童區無會員、無個資收集、無廣告追蹤、無金融商品導流。
- 工具包先預覽、再下載；不可建立不存在的下載成功、影片生成或客服功能。
- 公開內容不得包含私人 Drive 文件網址、內部策略、客戶資料或金鑰。
- 第三方書籍只可整理摘要與引用來源，不發布原 PDF 或完整章節。
- 價格、額度、版本功能和財金事實有時效性，新增時核對官方來源。
- 上線前執行 npm run build 與 npm run typecheck；驗證搜尋、閱讀、複製、下載及遊戲。
- 不宣稱另一個 AI 或 Claude Code 已參與，除非有實際協作紀錄。
